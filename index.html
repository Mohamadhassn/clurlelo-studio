clurlelo Studio

A private desktop tool for one creator's own YouTube channels.

clurlelo Studio is a personal application that runs on its owner's own computer. It helps the owner produce, publish and understand the performance of educational documentary videos on the owner's own YouTube channels (Money Plumbing and Map Power). It is not offered to the public and has no other users.

What it does

  • Uploads the owner's finished videos to the owner's channels and schedules them, with title, description, thumbnail and captions, only after the owner has approved each video.
  • Reads YouTube Analytics reports for the owner's own channels (views, watch time, audience retention) so the owner can learn what works and improve future videos.

How it uses Google data

The app signs in with Google OAuth and uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API) only for the owner's own channels. Data stays on the owner's computer and is never sold or shared. Details: Privacy Policy.
