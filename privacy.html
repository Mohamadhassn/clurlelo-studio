Privacy Policy

clurlelo Studio · Last updated: 2 October 2026

clurlelo Studio is a private desktop application used only by its owner to manage the owner's own YouTube channels. It is not offered to the public and has no other users.

YouTube API Services

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API and the YouTube Analytics API to upload the owner's videos; set their titles, descriptions, thumbnails and captions; schedule them; and read analytics reports (such as views, watch time and audience retention) for the owner's own channels.

How the data is used, stored and shared

  • Used only to publish the owner's videos and to help the owner understand the performance of their own content.
  • Stored only on the owner's own computer: OAuth tokens and analytics reports are kept locally.
  • Not sold, not shared with any third party, and not used for advertising.
  • The app does not use cookies, does not run on any server, and does not collect data about viewers.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: myaccount.google.com/permissions. Locally stored data can be deleted by removing the app's data folder from the owner's computer.
